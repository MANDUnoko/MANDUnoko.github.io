개인정보처리방침

시행일 · 최종 수정일: 2026년 10월 20일

프로젝트 체크리스트 운영자(이하 “운영자”)는 앱이 어떤 정보를 사용하고 어디에 보관하는지 다음과 같이 안내합니다. 이 방침은 프로젝트 체크리스트 데스크톱 앱과 이 안내 웹사이트에 적용됩니다.

1. 사용하는 정보와 목적

  • Google 계정 식별자와 이메일: 연결한 계정을 확인·표시하고 계정별 데이터를 구분하는 데 사용합니다.
  • OAuth 인증 토큰: 사용자가 승인한 범위에서 Google Drive에 접근하고 로그인을 유지하는 데 사용합니다. Google 비밀번호는 앱이 수집하거나 보관하지 않습니다.
  • 사용자가 입력한 내용: 프로젝트, 할 일, 완료 상태, 날짜·일정, 메모, 북마크와 화면 설정을 저장·불러오기·동기화하는 데 사용합니다. 사용자가 입력하는 내용에 개인정보가 포함될 수 있습니다.
  • 문의 내용: 이메일 문의 시 회신 주소와 문의에 포함된 정보를 문제 해결 및 답변에 사용합니다.

선택 기능: iCloud 캘린더와 기기 알림

사용자가 iCloud 연결을 켠 경우에만 Apple 계정 이메일과 앱 전용 암호로 Apple iCloud CalDAV 서비스에 연결합니다. 선택한 캘린더의 일정 제목·날짜·시간·메모·기간·연결 식별자를 불러오거나 저장·수정·삭제합니다. 연결한 일정은 Google Drive의 앱 데이터에도 포함되어 같은 Google 계정의 다른 기기로 동기화되고 이전 저장본에 남을 수 있습니다. Google 계정 연결만으로 iCloud에 자동 접근하지 않습니다.

Apple 앱 전용 암호, 기기별 연결·동기화 버전 정보, 알림 설정과 전송 기록은 OS 암호화 저장소로 기기에 보관하고 Google Drive나 운영자 서버에 전송하지 않습니다. Windows의 iCloud 기준본과 알림 처리 정보에는 암호화된 일정 내용이 포함될 수 있습니다. 알림 내용은 운영체제 알림 화면·알림 센터에 표시될 수 있습니다. 앱의 iCloud 연결 해제는 해당 기기의 저장된 앱 암호와 연결 정보를 삭제하며, iCloud 원본이나 Drive의 기존·과거 저장본을 자동 삭제하지는 않습니다. Apple 계정에서 앱 전용 암호를 취소할 수도 있습니다. iCloud 이용에는 Apple의 개인정보처리방침이 적용됩니다.

2. Google 접근 권한

앱은 openid, email, https://www.googleapis.com/auth/drive.appdata 권한을 요청합니다. 계정을 확인하고 이 앱이 생성한 Drive 앱 전용 데이터에만 접근하기 위한 권한입니다. 일반 Drive 문서 전체, Gmail, 연락처, Google Calendar에 접근하는 권한은 요청하지 않습니다. 앱에 입력한 일정과 Google Calendar는 별개입니다.

3. 저장 위치와 보관 기간

  • Drive의 앱 전용 공간: 업무 데이터는 연결한 계정의 숨겨진 appDataFolder에 저장합니다. 충돌 복구를 위해 이전 저장본이 남을 수 있으며 자동 만료일은 설정되어 있지 않습니다. 앱에서 항목을 지워도 이전 저장본에서 즉시 제거되는 것은 아닙니다.
  • 컴퓨터의 로그인 정보: OAuth 설정과 로그인 유지 정보는 운영체제 암호화 기능으로 보호해 로컬에 보관합니다. 앱에서 로그아웃하면 해당 로그인 유지 정보를 제거합니다.
  • 암호화 임시 파일: 연결·저장 실패 또는 정상 종료 시 미저장 변경이 있으면 계정별로 임시 보관합니다. 업로드한 내용을 다시 읽어 확인하면 삭제합니다. 동기화가 끝나지 않은 임시 파일은 로그아웃이나 앱 제거만으로 삭제되지 않을 수 있습니다.
  • 문의 이메일: 답변과 후속 지원에 필요한 동안 보관하며, 삭제 요청 시 법령상 별도 보관 의무가 없는 범위에서 삭제합니다.

앱은 업무 데이터를 운영자 소유의 별도 서버 DB로 전송·저장하지 않습니다. Google Drive에 저장된 데이터에는 Google의 보관·보안 정책이 적용됩니다. 로컬 암호화와 별도로 Drive 저장 내용에 앱 자체의 종단간 암호화는 적용하지 않습니다.

4. 제공·공유 및 Google 데이터 사용 제한

앱 데이터는 사용자의 기기와 Google 인증·Drive 서비스 사이에서 처리되며, 사용자가 iCloud 연결을 선택하면 연결한 일정은 Apple iCloud 서비스에서도 처리됩니다. 운영자가 사용자의 Drive 데이터를 별도 관리 화면에서 수집하거나 열람하는 기능은 없습니다. 사용자가 문의에 직접 첨부한 정보는 답변 과정에서 열람할 수 있습니다.

Google에서 받은 정보를 판매하거나 광고 타기팅에 사용하지 않으며, 범용 인공지능·머신러닝 모델의 학습에 사용하지 않습니다. 프로젝트 체크리스트의 Google API 정보 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy와 Limited Use 요건을 준수합니다.

5. 연결 해제·열람·삭제 방법

  1. 데이터 열람·수정: 같은 Google 계정으로 앱에 로그인해 저장된 내용을 확인하고 수정할 수 있습니다.
  2. 앱 로그아웃: 앱의 계정 메뉴에서 로그아웃할 수 있습니다. 로그아웃은 Drive에 남은 저장본 전체를 삭제하지 않습니다.
  3. Google 권한 해제: Google 계정의 타사 연결 관리에서 이 앱의 접근 권한을 해제할 수 있습니다. 권한 해제와 Drive 데이터 삭제는 서로 다른 작업입니다.
  4. Drive 저장본 전체 삭제: 앱을 완전히 종료한 뒤 Google Drive 설정의 ‘앱 관리’에서 이 앱의 숨겨진 앱 데이터 삭제 기능을 이용하세요. 삭제하면 이전 저장본도 복구할 수 없을 수 있습니다. 다시 연결하면 남아 있는 임시 변경이 업로드될 수 있으므로 아래 로컬 정리도 함께 확인하세요.
  5. 기기 내 정보 삭제: 동기화 상태와 필요한 백업을 확인한 뒤 앱을 완전히 종료하고 앱의 사용자 데이터 폴더를 삭제할 수 있습니다. Windows 기본 위치는 %APPDATA%\Project Checklist, macOS 기본 위치는 ~/Library/Application Support/Project Checklist입니다. 이 폴더에는 로그인 정보와 미동기화 변경이 포함될 수 있습니다.

6. 안내 웹사이트와 외부 서비스

이 웹사이트에는 운영자가 추가한 광고·방문자 분석 스크립트, 입력 폼, Google 로그인 기능이 없습니다. 페이지를 보는 것만으로 앱의 Drive 데이터에 접근하지 않습니다. 이 웹사이트는 GitHub Pages에서 호스팅합니다. GitHub는 로그인 여부와 관계없이 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub 개인정보처리방침에서 확인할 수 있습니다. 이메일 문의와 Google 서비스 이용에는 각 서비스 제공자의 정책도 적용됩니다.
